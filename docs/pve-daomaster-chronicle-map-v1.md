# 《梦潮：承道》道主人物命途地图 v1

版本：v0.4.3D-design

定位：本文定义九位道主的命途叙事、三幕结构和前三位开放道主的地图规则。本文不实现地图、事件或剧情系统。所有数值均为“首轮测试基线”。

## 1. 三幕结构

每位道主的普通 Run 使用三幕结构。

### 1.1 第一幕：起道

职责：

- 展示人物最初的问题。
- 教学基础玩法。
- 给出第一次关键选择。
- 让玩家理解该道主为什么会走上这条路。

玩法目标：

- 低复杂度敌人。
- 职业基础卡牌发挥空间。
- 第一次展示地图专属规则。

### 1.2 第二幕：失衡

职责：

- 展示其道路造成的代价。
- 让构筑开始分化。
- 出现针对惯用玩法的敌人。

玩法目标：

- 敌人开始针对单一策略。
- 异象代价更高。
- 精英要求玩家理解职业核心风险。

### 1.3 第三幕：成名

职责：

- 展示道主成为“一世三君五不归”的关键传奇。
- 多波精英。
- 多阶段 Boss。
- 完整构筑验收。

玩法目标：

- 检查输出、防御、资源、承道兽和道脉处理是否完整。
- 让职业强项和短板都被检验。

### 1.4 共享隐藏终幕

职责：

- 展示世界背面。
- 让九人故事汇合。
- 根据当前道主改变事件和结局片段。
- 不为每位道主制作完整独立第四幕。

隐藏终幕不是单纯更难的第四幕，而是对此前碎片叙事的反证和重组。

## 2. 碎片叙事来源

同一历史事件允许出现矛盾版本。

碎片来源：

- 世传：后世记录、民间传闻、宗门史书。
- 残响：战场、梦潮、遗物留下的片段。
- 道痕：规则痕迹，通常更接近事实但缺上下文。
- 敌证：敌人、Boss、随从或被击败者的证词。
- 自述：道主自身的记忆或自我辩护。

永久记录主推荐名：

《九人旧事》

备选：

《不归录》

规则：

- 首次 Run 更偏世传版本。
- 重复 Run 更偏亲历版本。
- 隐藏条件解锁背面版本。
- 背面版本可以推翻世传，但不能让前文全部无意义。

## 3. 三位开放道主地图规则

### 3.1 宰衡君：衡序值

衡序值是宰衡君命途中“稳定、秩序、可预测”的地图资源。

获得方式：

- 选择稳定和安全选项。
- 低回潮完成节点。
- 精准防御相关事件成功。
- 拒绝危险高收益异象。

效果：

- 高衡序提高地图可预测性。
- 可以提前显示部分节点类型。
- 可以关闭部分危险但高收益可能性。
- 可以降低某些随机事件的负面分支。

代价：

- 高衡序路线可能收益较低。
- 过度稳定会错过隐藏遗藏或高风险事件。

叙事含义：

- 晏无咎把混乱写入册页，但也可能把自己困在册页里。

### 3.2 织夜君：封存节点

封存节点是织夜君命途中“保留、延后、再启封”的地图规则。

规则：

- 每幕可以封存一次未进入节点。
- 该节点以后重新出现。
- 风险和奖励都会强化。
- 不能无限封存。

限制：

- Boss 节点不能封存。
- 已进入节点不能封存。
- 同一幕最多封存一次。

叙事含义：

- 裴缝月把未完成的夜留到以后，但夜不会原样归来。

### 3.3 负棺僧：安葬与负棺

安葬与负棺是负棺僧命途中“送别、承担、兑现”的地图规则。

安葬：

- 提供即时恢复。
- 或降低回潮。
- 或清理部分负面状态。

负棺：

- 积累棺印。
- 承担暂时负面效果。
- 后续在兽冢、事件或 Boss 前兑现收益。

限制：

- 负棺不能只给收益，必须带短期负担。
- 棺印兑现前可能影响敌人或事件分支。

叙事含义：

- 释无葬不是召唤死亡，而是替未归者背过一段路。

## 4. 宰衡君三幕草案

### 第一幕：荒册起衡

核心冲突：

- 晏无咎第一次发现荒阙记录正在失序。
- 他必须决定是修补边界，还是利用失序。

地图视觉主题：

- 破损册页、荒壤碑阵、青色边界线。

普通敌人主题：

- 失序书吏、醒潮残影、裂页虫、荒册守卫。

精英主题：

- 破界双卫。
- 抱火石兽。

Boss 叙事职责：

- 越界册官验证玩家是否理解阵势、火脉和边界控制。

故事碎片：

- 世传：宰衡君生来能定天下衡。
- 残响：荒册曾多次被他改写。
- 敌证：越界者认为他只是把混乱藏到了别人看不见的地方。

地图规则参与叙事：

- 衡序值越高，节点信息越清楚，但危险遗藏减少。

首次 Run 的世传版本：

- 晏无咎以秩序平定荒册。

重复 Run 的亲历版本：

- 玩家发现荒册失序与他的修补互为因果。

隐藏条件解锁的背面版本：

- 他并非第一次修补荒册，前几次失败被写进了缺页。

### 第二幕：衡界失准

核心冲突：

- 稳定规则开始伤害被规则排除的人。

地图视觉主题：

- 倾斜天平、断裂界线、静止潮痕。

普通敌人主题：

- 拒册流民、裂界兽、无衡客。

精英主题：

- 逆衡判官。
- 藏界祟影。

Boss 叙事职责：

- 迫使玩家在高衡序稳定路线和低衡序高收益路线之间承担代价。

故事碎片：

- 道痕：界线确实阻止了大灾。
- 敌证：界线也困住了该被救的人。
- 自述：晏无咎承认自己无法称量所有生命。

地图规则参与叙事：

- 高衡序关闭部分高收益危险事件，低衡序开放更多异象。

首次 Run 的世传版本：

- 宰衡君宁受骂名也守住边界。

重复 Run 的亲历版本：

- 玩家可看见被边界牺牲的细节。

隐藏条件解锁的背面版本：

- 某些牺牲并非必要，只是他当时还不知道其他解法。

### 第三幕：册定朝天

核心冲突：

- 晏无咎必须决定是否把自己也写入衡序。

地图视觉主题：

- 朝天册楼、悬空碑阵、青金界门。

普通敌人主题：

- 朝天试官、守册古灵、失衡天枝。

精英主题：

- 三册同审。
- 无名界守。

Boss 叙事职责：

- 检验玩家完整构筑：阵势、道脉控制、高阶兽、多波压力。

故事碎片：

- 世传：宰衡君以一册定朝天。
- 自述：他只是选择了最少人能活下来的版本。
- 残响：册页里还有被删去的名字。

地图规则参与叙事：

- 衡序值决定 Boss 前可见信息和隐藏代价。

首次 Run 的世传版本：

- 晏无咎成就宰衡君。

重复 Run 的亲历版本：

- 玩家看见成名背后的删改与犹疑。

隐藏条件解锁的背面版本：

- 他曾试图不成为宰衡君。

## 5. 织夜君三幕草案

### 第一幕：未醒王庭

核心冲突：

- 裴缝月发现王庭的夜不会自然结束。

地图视觉主题：

- 黑蓝王庭、未灭灯丝、帷幕长廊。

普通敌人主题：

- 未醒侍从、梦灯残影、夜雾巡卫。

精英主题：

- 守梦双鹤。
- 缝夜执灯。

Boss 叙事职责：

- 教学凝梦、留宵和保留压力。

故事碎片：

- 世传：织夜君能使残世不灭。
- 残响：王庭里很多人从未醒来。
- 自述：她并不确定醒来是否更好。

地图规则参与叙事：

- 封存节点第一次出现，教玩家延后选择。

首次 Run 的世传版本：

- 裴缝月保护了即将崩塌的王庭。

重复 Run 的亲历版本：

- 玩家发现被保护的人未必愿意继续梦下去。

隐藏条件解锁的背面版本：

- 王庭也在保护她不面对某个事实。

### 第二幕：残世留宵

核心冲突：

- 延后失衡变成积累债务。

地图视觉主题：

- 折叠街巷、倒挂月阶、封存节点裂痕。

普通敌人主题：

- 追梦债主、醒钟使、裂梦兽。

精英主题：

- 破宵官。
- 残世猎灯。

Boss 叙事职责：

- 针对过度保留，让玩家处理手牌拥挤与防御节奏。

故事碎片：

- 敌证：她所谓保护只是拖延。
- 道痕：拖延确实让某些人活到了第二天。
- 自述：她知道夜迟早会来讨债。

地图规则参与叙事：

- 被封存节点强化后返回，奖励和风险同时提高。

首次 Run 的世传版本：

- 织夜君留住长夜，救下残世。

重复 Run 的亲历版本：

- 玩家看见留住长夜带来的代价。

隐藏条件解锁的背面版本：

- 有些节点被封存，是因为她不敢进入。

### 第三幕：缝世成君

核心冲突：

- 裴缝月必须决定该缝合世界，还是让世界醒来后破裂。

地图视觉主题：

- 巨大夜幕、王庭裂缝、银线星图。

普通敌人主题：

- 醒世军、梦外证人、断线夜兽。

精英主题：

- 三醒审判。
- 缝世夜麟镜像。

Boss 叙事职责：

- 检验保留、爆发回合、道脉封存和高阶兽使用。

故事碎片：

- 世传：织夜君缝住了残世。
- 自述：她不知道缝住的是世界，还是自己的愧疚。
- 敌证：有人宁愿世界破裂也要醒来。

地图规则参与叙事：

- 第三幕封存节点会改变 Boss 阶段或结局片段。

首次 Run 的世传版本：

- 裴缝月成为织夜君。

重复 Run 的亲历版本：

- 玩家可选择更痛但更清醒的路径。

隐藏条件解锁的背面版本：

- 她曾亲手剪断过一条夜线。

## 6. 负棺僧三幕草案

### 第一幕：葬路初开

核心冲突：

- 释无葬第一次背起不属于自己的棺。

地图视觉主题：

- 白骨荒道、低灯墓坡、潮湿木棺。

普通敌人主题：

- 迷路亡客、棺前微魂、折骨兽。

精英主题：

- 阻葬者。
- 背棺古犀幼体。

Boss 叙事职责：

- 教学承道兽死亡、消耗和送归。

故事碎片：

- 世传：负棺僧能送所有亡者归路。
- 残响：有些亡者不愿被送走。
- 自述：他最初只是想替一个人走完路。

地图规则参与叙事：

- 安葬与负棺第一次出现，恢复和长期收益互斥。

首次 Run 的世传版本：

- 释无葬因慈悲负棺。

重复 Run 的亲历版本：

- 玩家发现慈悲也会变成执念。

隐藏条件解锁的背面版本：

- 第一口棺里可能没有尸体。

### 第二幕：无葬负身

核心冲突：

- 越来越多归路压到他身上。

地图视觉主题：

- 倒立坟河、骨桥、棺印雾。

普通敌人主题：

- 棺印债鬼、归路断兽、无葬僧影。

精英主题：

- 葬路双判。
- 古棺守门者。

Boss 叙事职责：

- 迫使玩家管理承道兽死亡时机，而不是无脑牺牲。

故事碎片：

- 敌证：他带走亡者，也带走活人的记忆。
- 道痕：棺印确实能换来保护。
- 自述：他知道自己有一天也需要被送归。

地图规则参与叙事：

- 负棺积累的棺印在兽冢或事件中兑现。

首次 Run 的世传版本：

- 负棺僧承受无葬者之苦。

重复 Run 的亲历版本：

- 玩家看见他并非总能送对地方。

隐藏条件解锁的背面版本：

- 某些棺印是他主动留下的债。

### 第三幕：送归不归

核心冲突：

- 释无葬必须决定最后是否送归自己。

地图视觉主题：

- 无尽葬门、潮下墓海、白骨天阶。

普通敌人主题：

- 归路守卫、空棺兽、无名亡证。

精英主题：

- 三棺同路。
- 背棺古犀。

Boss 叙事职责：

- 检验消耗堆、承道兽死亡、余骨和道脉转移。

故事碎片：

- 世传：负棺僧从不归来。
- 自述：不归也许是最后一种送归。
- 残响：有人曾在棺外听见他的声音。

地图规则参与叙事：

- 安葬路线偏恢复，负棺路线偏奖励和隐藏结局。

首次 Run 的世传版本：

- 释无葬成为负棺僧。

重复 Run 的亲历版本：

- 玩家能理解“不归”不是失败，而是选择。

隐藏条件解锁的背面版本：

- 他送归的最后对象可能是整条葬路。

## 7. 其余六位方向草案

以下仅提供三幕主题概览，不扩展到完整内容。

### 7.1 绝岸古尊

- 第一幕：无字碑前。
- 第二幕：剪枝成灾。
- 第三幕：定世不入。

方向：

- 预见、删牌、封锁分支、牺牲奖励换稳定。

### 7.2 绝渡君

- 第一幕：断桥起渡。
- 第二幕：万路皆绝。
- 第三幕：一渡无回。

方向：

- 弃牌、爆发、斩杀、断路。

### 7.3 缺名公

- 第一幕：名册缺页。
- 第二幕：无人承认。
- 第三幕：缺名立公。

方向：

- 生成、复制、改写、无名牌。

### 7.4 守灯侯

- 第一幕：边灯未灭。
- 第二幕：缺心守关。
- 第三幕：灯照不归。

方向：

- 守阵、护主、反击、边垣。

### 7.5 饮潮王

- 第一幕：吞潮入腹。
- 第二幕：海界反噬。
- 第三幕：饮尽成王。

方向：

- 回潮吸收、蓄能、吞灾、爆发。

### 7.6 断春夫人

- 第一幕：春令初断。
- 第二幕：枯荣倒转。
- 第三幕：断春成名。

方向：

- 承道兽成长、剪除、状态控制、枯荣转换。

## 8. 与 Run 地图系统的接口

命途地图需要向 Run 地图系统提供：

- 道主专属房间标签。
- 每幕视觉主题。
- 每幕敌人主题。
- 每幕 Boss 叙事职责。
- 道主地图资源。
- 隐藏条件。
- 故事碎片池。

Run 地图系统需要向命途系统返回：

- 当前幕。
- 当前节点。
- 已触发故事碎片。
- 已选择关键分支。
- 当前回潮。
- 当前道主专属地图资源。

## 9. 人工决定事项

- 《九人旧事》和《不归录》最终采用哪个名字。
- 首次 Run 是否强制走世传版本，还是允许直接出现亲历矛盾。
- 隐藏终幕解锁条件是否全道主共享。
- 三位开放道主的 Boss 名称是否在 v0.5.0 前冻结。
- 地图专属资源是否进入 RunState，还是独立 ChronicleState。
