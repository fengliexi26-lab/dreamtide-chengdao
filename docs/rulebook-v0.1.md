# 《梦潮：承道》v0.1 规则说明

本规则书对应 Godot 独立客户端原型 v0.1。目标是先验证战斗规则、卡牌数据结构和 PVE 基础流程，不包含联网 PVP、账号、数据库和完整美术表现。

v0.1 测试卡池为 30 张。人物牌属于人物阵列，不进入主卡组；主卡组 40 张与副卡组 15 张只包含每局会进入构筑与换备系统的卡牌。

## 1. 境界体系

境界决定单位的命源上限，也是伤害档位换算的基准。v0.1 境界从低到高如下：

| 序号 | 境界 | 命源上限 |
| --- | --- | ---: |
| 0 | 荒壤 | 150 |
| 1 | 命河 | 300 |
| 2 | 黄庭 | 600 |
| 3 | 天枝 | 1000 |
| 4 | 龙脊 | 1600 |
| 5 | 灵台 | 2500 |
| 6 | 垂天 | 3800 |
| 7 | 敛道 | 5500 |
| 8 | 朝天 | 7500 |
| 9 | 归墟 | 9000 |
| 10 | 帝阙 | 10000 |

单位有基础境界和临战境界。基础境界来自角色、关卡或构筑；临战境界是本局战斗内使用的境界，初始等于基础境界，可通过临战破境提高。

## 2. 命源值

命源值是单位生命资源。单位进入战斗时，命源上限由临战境界决定，当前命源默认等于上限。

命源降至 0 时，该单位战败。v0.1 暂不实现护盾、溢出治疗、濒死锁血和复活。

## 3. 伤害等级

卡牌和规则不直接写死固定伤害，而是写伤害等级。造成伤害时，根据使用者当前临战境界的命源上限自动换算为数值。

v0.1 默认换算：

| 伤害等级 | 换算比例 |
| --- | ---: |
| 微额伤害 | 临战命源上限的 5% |
| 小额伤害 | 临战命源上限的 10% |
| 中额伤害 | 临战命源上限的 18% |
| 大额伤害 | 临战命源上限的 30% |
| 爆发伤害 | 临战命源上限的 45% |

最终伤害向上取整，至少为 1。后续版本可加入防御、减伤、暴击、属性克制和连段修正。

## 4. 卡牌类型

v0.1 支持以下卡牌类型：

- 人物牌：Match 中用于选择本局道主的独立卡牌，不进入主卡组、手牌或承道位。
- 承道牌：秩序侧兽或混沌侧兽等承道单位，参与道脉适配。
- 道术牌 / 道法：即时道术效果，参与道脉适配。
- 道术牌 / 法阵：需要法阵位、阵势值或条件维持，不参与道脉适配。
- 道痕牌：长期标记、状态、印记或被动资源。
- 伏法牌：反制、埋伏、条件触发类卡牌。
- 域界牌：改变战场环境或阶段规则。
- 命器牌：装备与专武，参与适格和命契判定。

## 5. 人物阵列与道主

人物牌不是普通回合抽取的牌，也不是同一局中同时登场的承道单位。每名玩家携带 3 张人物牌，组成“人物阵列”。人物阵列服务于一场最多三局的 Match。

人物阵列规则：

- 每名玩家携带 3 张人物牌。
- 每局开始时，每名玩家只从尚未出战的人物牌中确定 1 张作为本局“道主”。
- 本局只有这一张人物牌生效。
- 三张人物牌不会在同一局同时出现。
- 人物牌不进入主卡组。
- 人物牌不进入手牌。
- 人物牌不进入承道位。
- 人物牌放入“道主位”。

本局道主决定玩家本局核心数据：

- 人物名。
- 境界。
- 道脉 `dao_tags`。
- 命源值。
- 道息。
- 阵势值。
- 回潮值。
- 道行值。
- `side`：`order` / `chaos` / `neutral`。
- 人物特性。
- 命器适格。
- 道法适配。
- 受到伤害修正。

v0.1 初始人物阵列包括：镜回少年、姜蘅枂、裴照川。数据文件为 `data/decks/starter_character_lineup.json`。

人物牌标准字段：

- `id`
- `name`
- `type: "character"`
- `dao_tags`
- `side`
- `base_realm`
- `base_life`
- `base_daoxi`
- `base_formation`
- `base_tide`
- `base_daoxing`
- `traits`
- `compatible_weapons`

人物牌不再使用旧字段 `life_source`、`dao_breath`、`formation_value`、`artifact_eligibility`。旧字段语义分别迁移为 `base_life`、`base_daoxi`、`base_formation`、`compatible_weapons`。

## 6. Match 规则

- 一场 Match 最多 3 局。
- 每局开始前，玩家从尚未出战的人物牌中选择 1 张作为本局道主。
- 本局结束后，该人物牌标记为已出战。
- 下一局不能重复选择已出战人物。
- 若一方先获得 2 局胜利，则 Match 结束。
- 若进入第三局，则使用双方剩余人物牌。

## 7. 承道牌分类

承道牌使用 `chengdao_kind` 字段区分两类：

- 秩序侧兽卡 `order_beast`。
- 混沌侧兽卡 `chaos_beast`。

人物牌使用 `type: "character"`，不使用 `chengdao_kind` 字段。

秩序侧兽卡规则：

- 代表稳定承道的生灵、异兽、古灵、圣地灵兽。
- 适合长期站场。
- 与秩序域界、稳定道痕、守御法阵配合。
- 在秩序域界中可获得稳定加成。
- 在混沌域界中可能受到削弱。

混沌侧兽卡规则：

- 代表回潮孽物、畸化生灵、失衡道种、祟物。
- 费用可更低或爆发更强。
- 登场时通常增加回潮值。
- 在混沌域界中增强。
- 在秩序域界中可能受到压制或伤害。

## 8. 侧性规则

卡牌可使用 `side` 字段表示侧性：

- 秩序 `order`。
- 混沌 `chaos`。
- 中立 `neutral`。

人物牌和域界牌都可以拥有 `side` 字段，取值为 `order`、`chaos` 或 `neutral`。域界侧性用于描述战场环境倾向；v0.1 只写入数据与规则说明，不实现复杂侧性结算。

## 9. 道脉适配

道脉适配用于判断卡牌是否适合当前单位的道路。

参与适配的牌：

- 道法牌参与道脉适配。
- 承道牌参与道脉适配。
- 命器牌参与适格和命契判定。

不参与适配的牌：

- 法阵牌不参与道脉适配，只检查境界、命源、阵势值和法阵位。

v0.1 中，卡牌数据使用 `dao_tags` 表示道脉标签。单位使用 `dao_paths` 表示自身道脉。需要适配的卡牌只要与单位有至少一个相同道脉标签，即视为适配；没有 `dao_tags` 的卡牌默认适配。

## 10. 法阵规则

法阵牌属于道术牌的法阵分支。法阵不检查道脉适配，只检查：

- 单位临战境界是否达到 `realm_requirement`。
- 单位当前命源是否满足 `life_requirement`。
- 单位阵势值是否满足 `formation_cost`。
- 是否存在可用法阵位。

施放法阵后，占用一个法阵位，并扣除对应阵势值。v0.1 默认每名单位有 1 个法阵位。

法阵规则保持：

- 法阵牌不参与道脉适配。
- 法阵牌不参与秩序 / 混沌侧性适配。
- 法阵效果文本可以明确针对道主、秩序侧兽卡或混沌侧兽卡。

## 11. 命器与命契反噬

命器牌可以带有 `fate_pact` 数据，表示命契或专武限制。

命器装备规则：

- 道主可以装备命器。
- 命契专武只允许对应道主装备。
- 秩序侧兽卡只能装备兽印、灵骨、道纹类命器。
- 混沌侧兽卡只能装备污染命器或畸化命器。
- 非适格单位接触命契专武时触发命契反噬。

当非适格单位抽到、检索到或装备命契专武时，触发命契反噬：

- 受到该牌配置的反噬伤害等级，默认小额伤害。
- 该牌立刻进入弃牌区。
- 本次获得或装备行为失败。

v0.1 适格条件包括：

- `required_owner_id`：只有指定单位可用。
- `required_dao_path`：单位必须拥有指定道脉。

## 12. 临战破境

每局战斗中，单位拥有临战境界。临战境界初始等于基础境界，只在本局有效。

单位通过道行值进行突破。v0.1 默认每突破一阶消耗：

| 目标境界 | 道行消耗 |
| --- | ---: |
| 命河 | 100 |
| 黄庭 | 200 |
| 天枝 | 350 |
| 龙脊 | 550 |
| 灵台 | 800 |
| 垂天 | 1100 |
| 敛道 | 1450 |
| 朝天 | 1850 |
| 归墟 | 2300 |
| 帝阙 | 2800 |

突破成功后，临战境界提升一阶，命源上限同步提高。v0.1 中，提高上限时当前命源增加同等差值。

## 13. 回合流程

v0.1 回合流程：

1. 回合开始：刷新临时状态，结算回合开始触发。
2. 抽牌阶段：抽 1 张牌。抽到命契专武时立刻进行适格判定。
3. 主阶段：使用道法、承道、法阵、命器等卡牌。
4. 战斗结算：执行伤害、治疗、阵势变化和破境检查。
5. 回合结束：清理临时效果，切换行动方。

当前版本只实现规则结构与基础测试，不实现完整 UI、动画、AI、联网同步和完整卡牌效果脚本。

## 14. 卡组构成

v0.1 构筑分为人物阵列、主卡组和副卡组：

- 人物阵列 Character Lineup：固定 3 张人物牌。
- 主卡组 Main Deck：固定 40 张。
- 副卡组 Side Deck：固定 15 张。

主卡组是每局实际抽取和使用的卡组。人物牌不进入主卡组，不进入手牌，不进入承道位。副卡组默认不进入抽牌堆，只用于 Match 局间换备。

主卡组规则：

- 主卡组固定 40 张。
- 主卡组不包含人物牌。
- 每局开始时，主卡组重新洗牌。
- 每局抽 5 张起始手牌。
- 每个己方回合抽 1 张。
- 每局结束后，手牌、场面、弃牌区、资源全部重置。

换备规则：

- 换入几张，必须换出几张。
- 换备后主卡组仍为 40 张。
- 换备后副卡组仍为 15 张。
- 副卡组不进入抽牌堆。
- Match 局间可以使用副卡组换备。

同名卡限制：

- 主卡组 + 副卡组合计最多 3 张。
- 命契专武、禁阵、特殊限制牌合计最多 1 张。
