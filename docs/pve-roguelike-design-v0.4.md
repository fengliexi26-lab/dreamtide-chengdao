# 《梦潮：承道》PVE 肉鸽规则设计 v0.4

## 1. 项目新定位

《梦潮：承道》从本地 PVP / 三局 Match 对战，正式转向类《杀戮尖塔》的单人 PVE 肉鸽卡牌游戏。

当前主线开发聚焦 PVE 肉鸽模式。旧的 PVP / Match / 三局轮换逻辑可以保留代码，但不再作为当前主模式启用。

核心循环：

```text
选择道主
↓
进入梦潮行旅
↓
进入节点
↓
战斗 / 事件 / 休整 / 精英 / Boss
↓
获得奖励
↓
强化牌组、获得道痕和命器
↓
推进到下一场战斗或下一层
```

## 2. 核心体验

游戏核心体验为 BCD 结合。

### B. 稳健防御

- 玩家需要通过阵势抵挡敌人意图。
- 敌人意图提前显示，玩家需要根据意图决定进攻、防御、召唤或保留资源。

### C. 召唤运营

- 承道兽是核心战力。
- 玩家通过召唤、保护、强化承道兽建立场面。
- 承道兽不是普通装饰，而是战斗运营核心。

### D. 风险交换

- 回潮值既是风险资源，也是剧情侵蚀值。
- 玩家可以通过提高回潮换取强力收益。
- 回潮会跨战斗保留，并影响事件、Boss 和后续战斗风险。

## 3. 九道主系统

道主选择界面不是三名主角，而是九名道主：

```text
一世 + 三君 + 五不归，共九人。
```

规则：

1. 开始 Run 时进入九宫格道主选择界面。
2. 九名道主对应小说设定中的“一世三君五不归”。
3. 每名道主相当于一个职业。
4. 每名道主未来拥有专属初始牌组、专属被动、专属卡池、专属道痕 / 命器倾向。
5. 玩家选择的是“道主投影 / 命途残响”，不是必须解释为本人亲自参战。
6. 第一版九宫格全部显示，但只开放 3 位：宰衡君 / 晏无咎、织夜君 / 裴缝月、负棺僧 / 释无葬。
7. 其余道主显示为“未解封”或“锁定”。
8. 九宫格卡片显示方式：主标题为称号，副标题为姓名；禁名、状态、层级、道途、玩法定位放详情面板。
9. 绝岸古尊作为最高难度 / 最终解锁 / 隐藏命途道主，第一版锁定。

## 5. 基础回合规则

采用类《杀戮尖塔》的大回合制：

```text
玩家完整回合
↓
敌人完整回合
↓
玩家完整回合
↓
敌人完整回合
```

### 玩家回合开始

1. 清空上一回合普通阵势。
2. 道息恢复到基础值。
3. 固定抽 5 张牌。
4. 重置承道兽攻击次数。
5. 重置道主道击。
6. 显示敌人当前意图。

### 玩家回合中

1. 可以打出多张牌，只要道息足够。
2. 可以召唤承道兽。
3. 可以使用承道兽攻击。
4. 可以使用道主道击。
5. 可以打出法阵、域界等持续牌。

### 玩家回合结束

1. 未使用的非“凝梦 / 保留”手牌自动进入弃牌堆。
2. 道息清空。
3. 进入敌人回合。

### 敌人回合

1. 敌人执行提前显示的意图。
2. 敌人攻击优先扣除玩家阵势，再扣命源。
3. 敌人可以通过特定意图攻击承道兽。
4. 敌人行动后刷新下一回合意图。
5. 若双方都未死亡，进入下一个玩家回合。

## 6. 抽牌与弃牌规则

1. 每个玩家回合开始固定抽 5 张。
2. 不采用“补满手牌”的方式。
3. 取消旧版手动 `discard_phase`。
4. 回合结束自动弃掉非“凝梦 / 保留”手牌。
5. 具有“凝梦 / 保留”的牌回合结束时不会被自动弃掉。
6. 牌堆系统包括抽牌堆、弃牌堆、消耗堆。
7. 抽牌堆为空时，洗弃牌堆形成新的抽牌堆。
8. 具有“消耗”关键词的牌使用后进入消耗堆，本场战斗不再进入循环。
9. 手牌上限暂定为 10。
10. 初始牌组建议为 12 张。
11. 取消旧 PVP 规则中的 40 张主卡组限制。

## 7. 道息规则

1. 道息相当于能量。
2. 基础道息建议为 3。
3. 玩家回合开始时，道息恢复到基础值。
4. 打牌消耗道息。
5. 回合结束时未使用道息清空。
6. 后续可通过道痕、命器、法阵、事件提高道息上限或临时获得道息。

## 8. 阵势规则

1. 阵势值是玩家当前回合的防御。
2. 敌人攻击时，先扣阵势。
3. 阵势不足时，剩余伤害扣命源。
4. 玩家新回合开始时，普通阵势清空。
5. 后续加入关键词“守阵”：守阵可以让部分阵势跨回合保留。
6. 承道兽没有阵势，只有生命。

## 9. 承道兽规则

1. 承道兽是本游戏核心战力之一。
2. 承道兽打出后进入中央战场。
3. 玩家最多同时拥有 3 只承道兽。
4. 每只承道兽拥有 `attack`、`life`、`side`、`dao_tags`、`chengdao_kind`。
5. 每只承道兽每回合可以攻击 1 次。
6. 承道兽可以被道法、法阵、道痕、命器强化。
7. 敌人可以通过特定意图攻击承道兽。
8. 第一版敌人攻击承道兽时采用随机目标。
9. 如果敌人意图为攻击承道兽，但玩家场上没有承道兽，则可以改为攻击道主。
10. 承道兽死亡后，普通承道兽进入弃牌堆，特殊承道兽进入消耗堆。
11. 特殊承道兽需要在数据中标记，例如 `is_special_summon: true` 或 `death_destination: "exhaust"`。

## 10. 回潮规则

1. 回潮值既是风险资源，也是剧情侵蚀值。
2. 回潮属于整个 RunState，不是单场战斗变量。
3. 回潮跨战斗保留。
4. 玩家可以通过混沌牌、事件选择、强力效果主动提高回潮。
5. 某些牌会根据回潮变强。
6. 某些事件、敌人和 Boss 会读取当前回潮值。
7. 第一版可以先实现回潮显示、回潮跨战斗保存、少量卡牌增加或读取回潮。
8. 后续版本再实现回潮阈值惩罚、回潮污染牌、回潮事件分支、Boss 根据回潮强化。

## 11. 卡牌类型重新定位

### 道法

- 普通战斗卡牌。
- 包含攻击、防御、抽牌、回潮控制、功能效果。

### 承道

- 召唤类卡牌。
- 打出后生成承道兽进入中央战场。

### 法阵

- 类似 Power 卡。
- 打出后本场战斗持续存在。
- 可以提供每回合收益或规则改变。

### 域界

- 场地类持续牌。
- 每场战斗最多 1 个域界。
- 会改变战斗环境或双方规则。

### 伏法

- 后续作为反制 / 延迟触发卡。
- v0.4 第一阶段可先弱化或占位。

### 道痕

- 最终改为遗物系统。
- 不进入手牌。
- 通过精英、事件、Boss、奖励获得。

### 命器

- 最终改为装备 / 遗物系统。
- 不进入普通抽牌循环。
- 可与道主适格性相关。

## 12. 敌人意图系统

1. 敌人不使用完整手牌和卡组。
2. 敌人每回合提前展示意图。
3. 敌人意图可以包括单次攻击、多段攻击、获得护盾、攻击承道兽、施加负面、召唤单位、根据回潮强化。
4. 敌人每回合执行一个意图。
5. 一个意图可以包含多段攻击，但不是敌人连续多个完整回合。
6. 敌人攻击承道兽时，第一版使用随机目标。
7. 意图必须在玩家回合提前显示，保证玩家可以应对。

## 13. RunState

后续需要建立 RunState，用于记录整个肉鸽行旅状态：

- 当前道主
- 当前命源
- 当前最大命源
- 当前牌组
- 当前抽牌堆 / 弃牌堆 / 消耗堆
- 当前回潮值
- 当前道行值
- 已获得道痕
- 已获得命器
- 当前层数
- 当前节点
- 当前事件状态
- 当前 Boss 状态

回潮值必须属于 RunState，并跨战斗保留。

## 14. 第一阶段版本路线

### v0.4.0：PVE 单场战斗基础改造

- 已完成。

### v0.4-design：PVE 肉鸽规则设计文档

- 当前任务。

### v0.4.1：RunState 与九宫格道主选择界面

- 开始 Run 前选择道主。
- 九名道主全部显示。
- 第一版开放宰衡君、织夜君、负棺僧。
- 其余道主锁定。
- 初始化该道主的初始牌组和被动。
- 建立 RunState。
- 回潮值归入 RunState。

### v0.4.2：PVE 回合规则重构

- 固定抽 5。
- 自动弃非凝梦手牌。
- 取消手动弃牌阶段。
- 建立抽牌堆 / 弃牌堆 / 消耗堆。
- 抽牌堆空时洗弃牌堆。

### v0.4.3：道主初始牌组与被动

- 宰衡君初始牌组。
- 织夜君初始牌组。
- 负棺僧初始牌组。
- 每位开放道主实现一个简单被动。

### v0.4.4：承道兽规则重构

- 普通承道兽死亡进弃牌堆。
- 特殊承道兽死亡进消耗堆。
- 敌人攻击随机承道兽意图。

### v0.4.5：战斗胜利奖励

- 三选一卡。
- 可以跳过。
- 奖励加入当前 Run 牌组。

### v0.4.6：连续战斗流程

- 战斗胜利后进入下一场。
- 回潮跨战斗保留。
- 命源、牌组、道痕、命器延续。
