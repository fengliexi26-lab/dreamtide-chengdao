# 《梦潮：承道》Run 地图与房间系统 v1

版本：v0.4.3D-design

定位：本文是 Run 地图、房间、动态生成和房间公平性的专题设计，服从 `docs/pve-combat-depth-master-v1.md`。本阶段只冻结设计，不实现地图代码。所有数值均为“首轮测试基线”。

## 1. 当前实现边界

当前已实现：

- 选择道主后进入 PVE 单场战斗。
- RunState 记录当前道主、当前命源、回潮、牌组和基础资源。
- 战斗胜负和重新开始战斗。

当前未实现：

- 地图生成。
- 房间节点。
- 战斗奖励。
- 连续战斗。
- 事件、商店、息壤台、遗藏。
- 精英、Boss、多敌人、多波战斗。
- 回潮影响地图。

## 2. 三幕 Run

首轮测试基线：

- 每位道主一个个人命途。
- 普通完整 Run 共三幕。
- 每幕一个阙域。
- 每幕实际经过 7 到 9 个节点。
- 三幕总计约 23 到 27 个房间。
- 共享隐藏终幕额外 4 到 6 个节点。
- 地图为有向无环分支图。
- 第一版不能回头。

三幕结构：

```text
第一幕：起道
→ 第二幕：失衡
→ 第三幕：成名
→ 可选共享隐藏终幕
```

每幕结束必须有 Boss 或阶段性守关战。

### 3.1 第一版房间

### 3.2 未来房间

- `beast_graveyard`

- `daomaster_shrine`
- `hidden_room`

未实现系统必须显示为锁定选项，不得伪装成可用。

## 4. 息壤台

息壤台是恢复、调整和承压后的选择点。

每次只能选择一项：

- 调息：恢复一定比例命源。
- 镇潮：降低回潮或处理负面状态。
- 悟法：升级一张牌。
- 整备：移除或调整卡牌。
- 养兽：未来强化高阶承道兽。

首轮测试基线：

- 调息恢复最大命源的 25%。
- 镇潮降低 2 点回潮。
- 悟法只在卡牌升级系统完成后开放。
- 整备只在删牌系统完成后开放。
- 养兽只在高阶兽系统完成后开放。

规则：

- 息壤台不能连续出现。
- Boss 前区域应有息壤台或梦市机会，但不保证必定恢复。
- 已锁定选项必须说明“后续版本开放”。

## 5. 精英房

精英房提供高风险高奖励。

支持结构：

- 精英与随从同时登场。
- 普通守卫波次后进入精英波次。
- 精英本体召援。

首轮测试基线：

- 每幕低难度路线可避开精英。
- 高风险路线可连续接近精英，但低难度不允许连续精英。
- 精英奖励应强于普通战斗，但不能成为唯一正确路线。

精英设计要求：

- 至少一个公开核心机制。
- 至少一个针对玩家惯用策略的行为。
- 不能第一次遭遇就无预告秒杀。

## 6. Boss 房

基础结构：

```text
守关敌人
→ 波次过渡
→ Boss 阶段战
```

波次默认保留：

- 命源。
- 承道兽。
- 手牌与牌堆。
- 道脉积蓄。
- 道主势。
- 战斗状态。

波次过渡可以：

- 获得少量道息。
- 抽少量牌。

波次过渡不恢复命源。

孤独型 Boss 可使用：

- 多阶段。
- 多部位。
- 环境机关。
- 临时召唤物。
- 可攻击核心。

规则：

- 不强制每个 Boss 携带普通小怪。
- Boss 必须拥有多个战术对象或规则变化。
- 阶段转换条件必须公开。
- 致命技能必须提前显示意图。

## 7. 动态生成

地图生成输入：

- `room_budget`
- `hard_constraints`
- `act_difficulty`
- `game_difficulty`
- `recovery_debt`
- `reflux_influence`

建议流程：

```text
确定幕与阙域主题
→ 生成路径骨架
→ 放置必需房间
→ 应用硬性公平约束
→ 根据回潮和难度调整风险节点
→ 校验路线长度和奖励密度
→ 固定随机种子
```

### 7.1 公平性约束

- 第一行仅普通战斗或低风险异象。
- 低难度至少有一条避开精英的路线。
- 同时存在高风险多精英路线。
- Boss 前区域存在息壤台或梦市机会。
- 息壤台不能连续。
- 低难度精英不能连续。
- 遗藏不能连续。
- 路线长度差异不能过大。
- 不允许存在奖励最多、恢复最多、战斗最少的绝对最优路线。

首轮测试基线路线长度差异：

- 同幕不同路线实际经过节点差不超过 2。

## 8. 回潮影响地图

回潮是 Run 级变量，应跨战斗保留并影响地图。

### 8.1 低回潮

- 信息稳定。
- 普通异象更多。
- 敌人行动更可预测。

### 8.2 中回潮

- 异化节点出现。
- 高收益敌人变体出现。
- 隐藏节点概率提高。
- 事件选项更极端。

### 8.3 高回潮

- 连战增加。
- 三祟污染事件出现。
- Boss 附加机制。
- 高风险高奖励节点增加。

原则：

- 高回潮不能只有惩罚。
- 低回潮不能只有无聊稳定。
- 回潮影响应提前可读，让玩家知道风险来自哪里。

## 9. 房间奖励预算

首轮测试基线：

普通战斗：

- 1 次卡牌奖励选择。
- 少量通用资源。

精英：

- 更高稀有度卡牌。
- 道痕或命器概率。
- 更高回潮或命源压力。

Boss：

- 幕间核心奖励。
- 重要道痕、命器或牌组方向选择。

异象：

- 提供风险交换。
- 可能增加回潮、删牌、换牌、获得特殊牌或改变地图信息。

梦市：

- 购买卡牌、删牌、道痕、命器。
- 回潮高时出现污染商品。

遗藏：

- 获得道痕、命器或稀有牌。
- 不应连续出现。

## 10. 多敌人与多波战斗

地图系统需要为战斗系统提供：

- 敌人组配置。
- 波次配置。
- 奖励配置。
- Boss 阶段配置。
- 是否保留承道兽和状态的规则。

多波战斗不应被伪装成连续普通房间。它是一个房间内的多个战斗阶段。

首轮测试基线：

- 普通战斗通常 1 波。
- 精英可 1 到 2 波。
- Boss 可 2 到 3 波或多阶段。

## 11. 首个垂直切片：宰衡君第一幕完整阙域

范围：

- 7 到 9 个实际经过节点。
- 2 到 3 条路线。
- 4 种普通敌人。
- 2 种精英配置。
- 一个两阶段 Boss。
- 一个息壤台。
- 2 到 3 种异象。
- 一个梦市。
- 一个遗藏房。
- 火脉和灼脉垂直切片。
- 宰衡君主动技能。
- 普通与高阶承道兽选择。
- 多敌人战斗。
- 多波战斗。

建议第一幕房间池：

- 普通战斗：醒潮残影、失序守卫、裂灯游魂、衡册虫。
- 精英：破界双卫、抱火石兽。
- Boss：越界册官，两阶段。
- 异象：缺页碑、潮下门、旧衡盘。
- 息壤台：荒阙息壤。
- 梦市：无灯梦市。
- 遗藏房：界尺遗藏。

这些名称只作为设计占位，不代表数据已创建。

## 12. 与人物命途的关系

Run 地图是道主人物命途的玩法表达：

- 第一幕教学职业基础。
- 第二幕针对惯用策略施压。
- 第三幕验收完整构筑。
- 隐藏终幕汇合九人故事。

道主人物命途详见 `docs/pve-daomaster-chronicle-map-v1.md`。

## 13. 人工决定事项

- 一幕是否固定 7 到 9 节点，还是根据道主变化。
- 回潮是否影响节点可见性，还是只影响节点内容。
- 梦市货币是否存在独立资源，或用命源、回潮、道主势相关代价替代。
- 息壤台“整备”是否允许删牌，还是只换牌。
- 隐藏终幕进入条件是否由回潮、道痕、Boss 行为或故事碎片决定。
